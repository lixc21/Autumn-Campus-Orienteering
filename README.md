# 赏秋校园定向

2026 年 10 月 31 日下午，我们在清华园办了一场校园定向。大家几人一队，按题目去找校园里的某块牌子、某棵树、某块石头，把上面的字填进手机里。

这里放的是那天用的答题网页和服务器程序。

## 玩法

题目分 A、B、C、D 四个区，每区 5 道，答对 4 道就能进下一个区。D 区过了，手机上会出现一个核验码，拿去签到处对一下，领一张明信片。

答题网页就是一个 HTML 文件，发到群里，用手机浏览器打开，输名字和口令就能玩。题目和答案都加密在文件里，只有答对了，下一个区才解得开，所以翻源码也看不到后面的题。

不联网也能答题。服务器只负责汇总每队答对了哪些题，方便工作人员看进度。

## 文件

- `网页/`：答题网页，题目和答案都写在 `data.js` 里
- `server/`：服务器程序 `app.py`，和工作人员看进度用的后台页面
- `build_encrypted.py`：把网页、题目、名单打包成一个加密的 HTML
- `资料/图片/`：题目里用到的照片

## 自己试试

需要 Python 3 和 Pillow。

```
pip install pillow
cp 名单.示例.csv 名单.csv
python build_encrypted.py
```

打开 `发布/赏秋校园定向.html`，用「张三」和口令「5555」登录。口令默认是全队学号后四位加起来。顺带还会生成几张工作人员用的表，在 `工作人员/` 里。

想接上服务器，先把 `网页/data.js` 里的 `api` 改成自己的地址，重新打包，把 `server/` 整个传到服务器上，再运行：

```
python3 app.py import teams.csv
python3 app.py serve
```

服务器只用到 Python 自带的库，前面用 nginx 转发，配置在 `server/nginx.conf`。
